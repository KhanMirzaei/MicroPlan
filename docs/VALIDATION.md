# Validation status

Version 0.1.0 is a research prototype, not a validated experimental-design authority.

26 automated software tests cover deterministic allocations, capacity and position uniqueness, subject bundles, fixed and permitted batches, contradictory restrictions, control carry-through, complete confounding, balanced overlap, no/total sample loss, technical-replicate accounting, budget costs including controls, invalid IDs/settings, output preservation, error handling and full report generation.

Testing uses synthetic fixtures. No real study, wet-laboratory execution, independent statistical audit, HPC scheduler run or large-manifest resource benchmark has been performed. A balanced processing plan is not a power calculation or assurance of biological reproducibility. The program does not claim optimality or support all laboratory designs. See METHODS.md for assumptions.
